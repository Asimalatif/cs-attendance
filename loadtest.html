Load test: 7 days of fake attendance

Every teacher of the timetable "marks" every period of the days you choose, with random P / A / L, the way the app does it (one save per period). All marks go into a COPY of the month workbook: the real attendance sheets, the Attendance Index and the change history are never written. Admin login only. Run it in the evening, when real teachers are not marking.

1 · The copy

Open the real November attendance workbook in Google Sheets → File › Make a copy (name it "TEST COPY November"). Paste the copy's link here. The server refuses a real workbook.

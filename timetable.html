Timetable settings

Tick the sections that run in the evening. Clash checks (teacher, room, section) are done only within the same shift: an evening section is never compared with a morning section. Ticking whole class marks every section of that class (including sections added later). Morning and evening sections of a class are shown on separate pages because they can have different timings.
Credit hours = number of days (theory + practical) a subject is taught in a section per week. Set Morning and Evening limits separately for each subject (e.g. Physics morning 5-5, evening 4-4). For evening sections the evening limit is used; if it is blank the subject's morning limit is used. If a subject has no limits at all, the default rule below is used (evening default for evening sections, otherwise the morning default). If everything is blank the subject is not checked. F.A programs are never checked.

Set the start and end time of every period, separately for the morning and the evening shift. Each period can have its own length (40, 50 or 60 minutes…). An evening period left blank uses the morning timing. Use Quick fill to generate equal periods, then change individual periods if needed. Use “Remove last period” to delete extra periods, then press “Save settings”: the number of periods you leave in the list is saved and the removed ones are gone. “Period columns always shown” is the minimum number of period columns of every page of that shift (more columns appear automatically when a period beyond it is used). Times are shown in 12-hour style on the timetable.
Rooms listed here appear in every room dropdown. A new room is saved under the Room column of the DropdownData sheet. You can also add a room from any room dropdown with ＋ Add new room…. Press ✕ beside a room to delete it from the list (a room that is still used in the timetable cannot be deleted). “R # 06/55” and “R # 06/55 (EVENING)” are treated as one room.
